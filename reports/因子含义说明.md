# 因子含义说明（策略与信号负责人 · 陶雅茹 · 11/16 交付）

> 配套代码：`src/factors/factor_calc.py`（因子计算与打分）、
> `src/factors/run_small_sample_check.py`（小样本检查脚本）。
> 本文同时是答辩问题"三个因子分别有什么金融含义 / 为什么标准化 / 为什么选这些权重"的答案底稿。

## 一、三因子定义与金融含义

### 1. 动量因子（权重 50%）

- **计算**：`momentum = close[t] / close[t-60] - 1`，即过去 60 个交易日（约 3 个月）的区间收益率。
- **方向**：越高越好。收益率越高，说明该股近三个月涨势越强。
- **金融含义**：动量效应（Momentum Effect）是金融市场中最著名的异象之一——过去表现强势的股票在短期内倾向于延续强势。Jegadeesh & Titman (1993) 在美股发现 3–12 个月动量组合显著跑赢市场；A 股研究普遍认为动量效应在中短周期（1–3 个月）上弱于美股、甚至存在反转倾向，这正是本项目要用真实数据检验的问题之一。
- **选择 60 日的理由**：3 个月是文献中最常用的动量窗口之一，月频调仓框架下既能捕捉趋势又不过度敏感于单日噪声。

### 2. 均线因子（权重 30%）

- **计算**：`ma_bias = close[t] / MA20[t] - 1`，当前价格相对 20 日均线的偏离度。
- **方向**：越高越好。价格为正偏离（站上均线）说明短期趋势向上。
- **金融含义**：均线是技术分析中"趋势跟随"的经典工具。价格持续位于均线上方，通常被解读为买方力量占优的确认信号；20 日（约一个月）与本项目月频调仓节奏匹配。它与动量因子相关但不相同：动量看区间总涨幅，均线偏离看当前价格相对近期均值的位置，后者对最近走势更敏感。
- **仓位定位**：作为动量的"确认因子"，权重次于动量。

### 3. 低波动因子（权重 20%）

- **计算**：`low_vol = -std(过去 20 日日收益率)`，对 20 日收益标准差取负号。
- **方向**：取负后统一为"越大越好"——波动越小，该值越接近 0，得分越高。
- **金融含义**：低波动异象（Low Volatility Anomaly）——许多市场中发现低波动股票长期风险调整后收益反而更高（Baker, Bradley & Wurgler 2011）。加入该因子一方面捕捉这一效应，另一方面降低组合整体波动、控制最大回撤，改善夏普比率。
- **取负号的理由**：三个因子统一为"分数越大越好"后，才能直接加权求和，避免方向混乱。

## 二、打分与标准化方法

### 为什么必须标准化

三个因子量纲完全不同（动量是 ±几十个百分点、均线偏离是 ±几个百分点、波动率恒为正且取负后 ≤ 0），直接相加会让动量因子数值上"淹没"其他因子。标准化后三者都落在同一尺度，权重 50/30/20 才真正代表设计意图。

### 为什么用排名法而不是 z-score

1. **对极端值稳健**：A 股个别股票短期翻倍或腰斩，z-score 会被极端值拉偏，排名法不受影响；
2. **天然落在 [0, 1]**，三个因子加权后综合得分仍在 [0, 1]，便于解释；
3. **横截面相对选股**：我们本质只关心"谁比谁强"，不关心强多少，排名法正好匹配这一需求。

### 具体规则（见 `rank_normalize`）

- 每个交易日，对当日**有效**（非 NaN）股票按因子值排名：`score_01 = (rank - 1) / (n - 1)`，n 为当日有效股票数；
- 并列值取平均名次；
- 窗口不足（上市/数据少于 60 或 20 个交易日）→ 因子为 NaN → 不参与当期排名与选股（自动排除次新股）；
- 当日仅 1 只有效股票时记 0.5（中性分，已在代码注释说明）。

### 综合得分

```
score = 0.50 × momentum_01 + 0.30 × ma_bias_01 + 0.20 × low_vol_01
```

三个因子任一为 NaN，综合得分即 NaN，该股当期不入选。

**权重设计理由**：动量是策略的主要收益来源，给最高权重；均线是趋势确认，居中；低波动主要负责风险控制而非收益，权重最低。该权重为初始设定，后续参数敏感性分析（11/24 单/双/三因子对比、权重实验）将验证其合理性并可能调整。

## 三、调仓与选股规则（与全组统一标准一致）

1. 每月**最后一个交易日**收盘后计算三因子与综合得分（`month_end_dates` 识别信号日）；
2. 选综合得分最高的 **5 只**股票，**等权**分配资金；
3. **下月第一个交易日**成交：先卖出不再持有的，再买入新入选的（由回测负责人 11/19–11/20 的引擎执行）；
4. 每次调仓保存当日完整排名表（`select_top_k` 已输出明细），用于答辩时解释"为什么买了这些股票"；
5. 备用处理规则（股票不足 5 只 / 停牌 / 数据缺失）：候选不足 5 只时按实际数量等权；停牌或当日无数据股票不参与排名（NaN 规则）；极端情况下全部现金持有——完整规则在 11/18 signals.csv 交付时与回测负责人对齐后写入 README。

## 四、防未来数据泄露设计

- 所有因子只用 `rolling` / `shift` 向后看：t 日因子只依赖 t 日及以前的价格；
- 横截面排名只用同一交易日的因子值；
- `run_small_sample_check.py` 第 5 项检查提供程序化验证：把数据截断到任意日 t 重算因子，t 日因子值与全样本计算完全一致（已通过）。

## 五、已知局限（如实写入报告）

1. 三个因子全部基于**价格量数据**，未使用基本面数据，信息来源单一；
2. A 股动量效应历史上不稳定，样本外可能出现失效；
3. 排名法丢弃幅度信息，极端强势股与略强股得分差距可能被压缩；
4. 未考虑涨跌停/停牌导致的成交不可行（由回测引擎的成交规则约束）；
5. 权重 50/30/20 为经验设定，需敏感性分析验证。
